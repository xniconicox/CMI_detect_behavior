# テスト実行ガイド

このリポジトリでは `pytest` を用いたユニットテストを提供しています。主に `tests/` ディレクトリにテストスクリプトを配置しています。

## 1. 依存パッケージのインストール

テスト実行には `requirements.txt` の依存パッケージが必要です。まだインストールしていない場合は次のコマンドでセットアップしてください。

```bash
pip install -r requirements.txt
```

## 2. テストの実行

ルートディレクトリで以下を実行すると、すべてのテストが実行されます。

```bash
pytest -q
```

実行結果が `1 passed` となれば成功です。

## 3. GitHub Actions

`.github/workflows/test.yml` で定義されたワークフローにより、プルリクエストやブランチへの push 時にも自動で `pytest` が実行されます。CI 上で失敗した場合は、ローカルで同じコマンドを実行し、エラー内容を確認してください。

## 4. テスト内容の概要

現在のテストでは `src/utils/pipeline.py` の `Preprocessor` クラスを対象としています。ダミーの DataFrame を用いて以下を検証します。

- 各ビルダーの出力形状が期待どおりか
- キャッシュファイルとメタ情報の MD5 が一致するか
- `Preprocessor.save()` で保存した pkl を `load()` し、`transform()` した結果が同一か

今後テストを追加する際は `tests/` 配下にファイルを追加してください。
